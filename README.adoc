= Demo for querying Confluent Platform with Prometheus

This demo show how to use Prometheus for querying metrics from Confluent Cloud.
Please have a look at this article for details: https://www.confluent.io/blog/bring-your-own-monitoring-with-confluent-cloud/

== Preconditions

In your Confluent Cloud organization, create an API key, assign it to a service account and grant `MetricsViewer" permissions.
Customize the Prometheus configuration file template `docker/prometheus/prometheus-confluent-cloud-service-quota-exporter-template.yml` and copy it to `docker/prometheus/prometheus.yml`.
Configure the experimental Confluent Cloud Quota API export, by going into the folder `python`, copy the file `example-config.yaml` to `config.yaml` and customize it (optionally, the code will use the API Key specified in your .env file by default).

Optional: If you want to try the kafka-exporter, copy the .env-template to .env and customize it.

Note: We also provide an alternative file called `prometheus-json-exporter-template.yml` which uses json_exporter for querying the Quota API. However, this exporter misses important features, such as support for paginated results.

== Running Prometheus

Then enable the docker compose profile by setting:

```console
export COMPOSE_PROFILES=kafka-exporter
````

Start the containers by running (if you want to use filebeat for fetching logs):

```console
docker compose up -d
```

Stopping the containers with removal of all created volumes (be careful!):

```console
docker compose down -v
```

Cleaning up (CAREFUL: THIS WILL DELETE ALL UNUSED VOLUMES):

```console
docker volumes prune
```

== Usage

Access `prometheus` with your web browser here:

* URL: `http://localhost:9090`

Access `grafana` with your web browser here (username: grafana, password: grafana):

* URL: `http://localhost:3000`
